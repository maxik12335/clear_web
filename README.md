Папки
/assets - фото и видео. Формат смысл - папка, нумерация 1,2,3 ...
/Components - любые компоненты, если мелкие то можно ui создать папку
/Pages - страницы
/Setcion - если компонент большой для страницы его можно вынести в секцию

стили
/styles/base
  /globals.css - глобальные универсальные классы (контейнеры, стрелки, hover эффект и всё что используется почти везде)
  /rest.css - обнуление стилей
  /tokens.css - кипричи которые влияют на все содержимое на сайте ... если трогать то по минимуму
  /typography.css - типография (классы от мелкого шрифта до заголовка h1)

сторонние функции и разная логика
/utils
